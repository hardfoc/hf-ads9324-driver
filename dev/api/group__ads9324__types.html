◆ OversamplingClock

enum class ads9324::OversamplingClock : uint8_t
strong

Where the oversampled conversions are triggered (SBASB22 §7.3.11.2).

Enumerator
Internal 

One CONVST falling edge; the chip triggers the other N−1 conversions itself (DIG_FILTER.INT_TRIG_MODE = 1, Figure 7-17).

External 

Every conversion needs its own CONVST falling edge: the driver pulses CONVST N times per snapshot (Figure 7-16). Regular sampling, best antialiasing; the chip reports one averaged result after N edges.

constexpr int32_t ads9324::GainCorrectionFor ( int32_t  measured,
int32_t  expected 
)
inlineconstexprnoexcept

GAN_AINn value that scales a measured code onto the expected one (SBASB22 Equation 3).

GAN = (expected − measured) / measured × 65536, rounded to nearest, for two's-complement codes (measure near full scale with the gain correction at 0, after the offset correction).

Parameters
measuredTwo's-complement code read for a known input (not 0).
expectedCode that input should give.
Returns
The correction; 0 when measured is 0. Outside kGainMin to kGainMax the error is too large for the register and ads9324::ADS9324::SetChannelGain rejects it.

◆ OffsetCorrectionFor()

constexpr int32_t ads9324::OffsetCorrectionFor ( int32_t  measured,
int32_t  expected 
)
inlineconstexprnoexcept

OFS_AINn value that moves a measured code onto the expected one (SBASB22 Equation 1).

The chip adds OFS_AINn in quarter LSBs: output = (code × 4 + OFS) / 4.

Parameters
measuredCode read with the reference input applied (offset correction at 0).
expectedCode the input should give (0 for a shorted differential input).
Returns
4 × (expected − measured); outside kOffsetMin to kOffsetMax the error is too large for the register and ads9324::ADS9324::SetChannelOffset rejects it.
