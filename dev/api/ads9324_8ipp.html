Detailed Description

Template implementation for ads9324::ADS9324.

Copyright
Copyright (c) 2026 HardFOC. All rights reserved.

Header-only .ipp (same pattern as hf-ads7952-driver). Public contracts live in ads9324.hpp; this file documents the silicon sequences that are not obvious from the signatures: banked PGA nibble merge, two-frame register read, CONVST/DRDY handshake, and SDOUT burst unpack.

Bus errors: every frame goes through detail::Transfer(); when the port reports a failure the operation stops there, bool calls return false and the reads return Error::SpiError. Cached state (bank, data format, lanes, channel-count mode, PGA configuration) is only updated after the frames that change it on the chip were transferred.
