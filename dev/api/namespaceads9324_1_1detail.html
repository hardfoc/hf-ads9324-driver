Call the port's transfer() and return its status.

A bool result is returned as-is; a void transfer (the earlier contract) is treated as always successful. Any other return type is rejected, so an SDK status code (for example an esp_err_t, where 0 means success) cannot be mistaken for a bool.

template<typename Host >
constexpr bool ads9324::detail::kHostDrivesReset = requires(Host& host) { host.ResetWrite(true); }
inlineconstexpr

True when the host port drives the RESET pin: it has ResetWrite(bool high).

Optional hook, detected on the derived class (it is not part of HostInterface): ResetWrite(false) drives the active-low RESET pin low, ResetWrite(true) releases it. Ports without it keep compiling; ADS9324::HardwareReset then returns false.
