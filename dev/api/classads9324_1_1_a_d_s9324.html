Detailed Description

template<typename SpiType, typename HostType>
class ads9324::ADS9324< SpiType, HostType >

Main driver class for the ADS9324.

Not thread-safe. The host serializes access if multiple tasks share one instance.

Bus errors: when the port's transfer() returns false, the call that sent the frame stops there; bool functions return false, ReadDeviceId returns 0 and the reads return Error::SpiError. Cached state is only updated after the frames that change it were transferred.

Template Parameters
SpiTypeCRTP type implementing SpiInterface (3-byte config frames + conversion burst).
HostTypeCRTP type implementing HostInterface (CONVST / DRDY / delay).

◆ HardwareReset()

template<typename SpiType , typename HostType >
bool ads9324::ADS9324< SpiType, HostType >::HardwareReset ( )
noexcept

Pulse the RESET pin, wait tPU, then bring the chip back to the driver's defaults.

RESET is an active-low asynchronous input that resets all digital circuitry (SBASB22 §7.4.1, pin 32); the device needs tPU after a reset (§7.4.2, §5.7: 30 ms). Sequence: ResetWrite(false), wait ADS9324_CFG::RESET_PULSE_US, ResetWrite(true), wait ADS9324_CFG::POWER_ON_DELAY_MS, then the same reprogramming as SoftwareReset (BANK_SEL, GEN_CFG3, PGA defaults; the reference source returns to ReferenceSource::RefselPin).

Needs the optional ResetWrite(bool high) hook on the host port (HasHardwareReset).

Return values
trueReset pulsed and the chip reprogrammed.
falseThe port has no ResetWrite(), or reprogramming failed (then IsInitialized is false).

Pulse CONVST, wait DRDY (or fallback delay), clock all enabled channels.

Returns
Snapshot with Snapshot::valid_mask bits set for clocked channels. Error::NotInitialized, Error::Timeout or Error::SpiError (the burst transfer failed) on failure.

The ADC disconnects its inputs for TWAIT = 125 ms (Table 7-7) and measures its own offset and/or gain error; the correction stays applied until AdcCalMode::Disabled or a reset. Enable or disable the block-average oversampling filter.

Sequence (SBASB22 §7.3.11.2): before the first use, GEN_CFG5 = AVG_MODE_OVR_EN, then AVG_MODE_OVR_EN | AVG_MODE; then DIG_FILTER with BLK_AVG_OSR and INT_TRIG_MODE (reg::DigFilterValue), followed by a 0→1→0 edge on DIG_FILT_SYSREF to reset the accumulator.
