Detailed Description

CRTP SPI and host-pin contracts for ADS9324.

Copyright
Copyright (c) 2026 HardFOC. All rights reserved.

The silicon uses one SPI port for 24-bit configuration frames (address + data) and, in the driver's default 1-lane SDOUT mode, the same SDI/SCLK/CS plus SDOUT for conversion bursts. CONVST and optional DRDY are GPIO, not SPI.

Implement both CRTP bases on the platform (see examples/esp32/main/esp32_ads9324_bus.hpp).
