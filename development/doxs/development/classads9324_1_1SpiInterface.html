Detailed Description

template<typename Derived>
class ads9324::SpiInterface< Derived >

CRTP SPI contract. CS is owned by the implementation (one CS per call).

Configuration traffic is always 3 bytes, MSB first, SPI mode 0 (CPOL=0, CPHA=0), latched on SCLK rising and decoded on CS rising (SBASB22 §7.5). Conversion readout is a single CS-low burst of num_channels * 2 bytes in 16-bit 1-lane SDOUT mode (32 bytes for 16 ch).

Template Parameters
DerivedPlatform class that implements transfer.
Note
The driver does not toggle CS. Wrap each transfer in CS-low for the entire len — do not deassert between bytes of one frame.
Warning
Do not share this CS with another device on the same call.
