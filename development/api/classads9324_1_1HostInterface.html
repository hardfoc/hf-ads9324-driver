Detailed Description

template<typename Derived>
class ads9324::HostInterface< Derived >

CONVST / DRDY / delay pins. DRDY may be unused (HasDrdy() == false).

Template Parameters
DerivedPlatform class that implements the five methods below.

CONVST is active-high: a high pulse then low starts conversion on the falling edge (SBASB22; pulse width ≥ 50 ns). Map host GPIO “active” to CONVST high.

When HasDrdy returns false, the driver waits ADS9324_CFG::CONV_FALLBACK_US after CONVST instead of polling.
