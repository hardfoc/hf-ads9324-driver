# ADS9324 Driver API reference {#mainpage}

The classes, members and types of the HardFOC ADS9324 driver, generated from the headers.

Start with ads9324::ADS9324, the driver, and ads9324::SpiInterface and ads9324::HostInterface, the contracts your
platform port implements. Channel settings, results and error codes are in ads9324_types.hpp; register addresses
and frame packing are in the ads9324::reg namespace; compile-time defaults are in the ADS9324_CFG namespace.

The guides, with examples that compile, are on the documentation site: <a href="../">ADS9324 Driver
documentation</a>.
