Detailed Description

template<typename SpiType, typename HostType>
class ads9324::ADS9324< SpiType, HostType >

Main driver class for the ADS9324.

Not thread-safe. The host serializes access if multiple tasks share one instance.

Template Parameters
SpiTypeCRTP type implementing SpiInterface (3-byte config frames + conversion burst).
HostTypeCRTP type implementing HostInterface (CONVST / DRDY / delay).

Program one channel's PGA type, range, bandwidth, and CME bit.

Read-modify-writes the shared PGA_CONFIG pair register (even/odd nibble) and PGA_BW_SEL. API channel 0 = AIN1.

Parameters
channel0–15.
cfgDesired analog front-end.
Return values
trueBoth registers updated and cached in GetChannelConfig.
falseChannel out of range or SPI failed.

PGA_CONFIG_AINxy holds two channels: even local index in bits [7:0], odd in [15:8]. Bandwidth lives in PGA_BW_SEL (2 bits × local index).

◆ ReadSnapshot()

Pulse CONVST, wait DRDY (or fallback delay), clock all enabled channels.

Returns
Snapshot with Snapshot::valid_mask bits set for clocked channels. Error::NotInitialized or Error::Timeout on failure.
Precondition
EnsureInitialized succeeded.

One CS-low burst of N×2 (16-bit) or N×3 (24-bit) bytes. 24-bit mode still uses the first two bytes as the 16-bit code. Channel i in the burst maps to API channel i when ADC_NUM_SEL is All16.
